La valeur absolue

une distance, une définition, des équations

Valeur absolue = distance à 0

|4| = 4
|−4| = 4
|−2,5| = 2,5  ·  |0| = 0
si x ≥ 0|x| = xsi x < 0|x| = −x  (on change le signe)
ex. : |−4| = −(−4) = 4

Distance entre deux nombres

|x − a| = distance entre x et a
|7 − 3| = |4| = 4
|3 − 7| = |−4| = 4
l’ordre ne change rien à la distance

Équation

Méthode : |A| = b

si b > 0 : A = b ou A = −b → 2 solutions
si b = 0 : A = 0 → 1 solution
si b < 0 : aucune solution
avec du x des deux côtés : deux cas, et on garde seulement les solutions qui respectent le cas
et on vérifie toujours en remplaçant !
